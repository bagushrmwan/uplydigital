# Uply Digital V12

## Baru
- Tombol **Daftar Gratis** sekarang langsung membuka Dashboard bila pelanggan sudah login; admin diarahkan ke Panel Admin.
- Login dan registrasi pelanggan tanpa checkout tertunda sekarang langsung menuju Dashboard.
- Tema tampilan **Sesuai perangkat / Terang / Gelap** dan pilihan tersimpan di perangkat.
- Halaman detail produk bergaya storefront modern: visual produk, paket, fitur utama, stok, jumlah, keranjang, order langsung, deskripsi, garansi, dan area review.
- Keranjang belanja slide-in dengan jumlah, subtotal, hapus item, dan lanjut checkout.
- Halaman checkout diperbarui: metode pembayaran, kontak, WhatsApp, catatan admin, ringkasan sticky, jumlah dan total.
- Catatan pelanggan dari checkout benar-benar tersimpan ke order PostgreSQL.
- Dashboard pelanggan memiliki **Status Member** Explorer / Member / Reseller berdasarkan jumlah order selesai.
- Section Kategori Populer dan footer informatif baru.
- Floating support button untuk WhatsApp/Pusat Bantuan/Pesanan.
- Tetap responsif desktop dan mobile.

## Tetap dipertahankan
- Vercel Native + PostgreSQL/Neon
- Login pelanggan/admin
- Midtrans
- Transfer manual + bukti pembayaran
- Invoice pelanggan
- Inventory satu per satu
- Panel admin, order, customer, bank, audit log
