# CHANGELOG — Uply Digital V25

## Dashboard Admin Lengkap
- KPI omzet, omzet harian, payment review, pelanggan, low-stock, notification count.
- Funnel order → paid → completed.
- Grafik omzet 14 hari.
- Ranking produk dan payment mix.
- Notification Center.

## Smart Voucher System
- Nominal / persen.
- Minimum transaksi dan maksimal diskon.
- Kuota global dan limit per user.
- Filter kategori / produk.
- Voucher pelanggan baru.
- Jadwal mulai/berakhir.
- Validasi server-side dan usage ledger.

## Balance System
- Saldo per customer.
- Admin credit/debit.
- Ledger setiap mutasi.
- Saldo dapat dipakai di checkout.
- Refund otomatis saat pending order dibatalkan/kedaluwarsa/payment gagal.

## Role Connector
- Customer → Member → Reseller → VIP berdasarkan order selesai / omzet.
- Admin dapat override manual atau mengembalikan ke Auto.

## Multi Payment
- Midtrans otomatis.
- Transfer manual.
- QRIS manual upload dari Panel Admin.
- Saldo Uply.
- `PAYMENT_MODE=hybrid` didukung.

## Smart Stock
- Low-stock threshold per product.
- Alert dashboard.
- Notification saat stok manual/inventory menyentuh threshold.
- Inventory auto-delivery tetap memakai row locking.

## Reporting
- 30-day recap.
- Gross / discount / net sales.
- Product ranking.
- Payment mix.
- Status recap.
- Export CSV.

## Dokumentasi
- Tab Dokumentasi baru di Panel Admin.
- Panduan workflow order, payment, stock, voucher, balance, role, reporting, dan keamanan Top Up.
