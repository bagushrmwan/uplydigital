# Tutorial Hapus Produk V27.1

1. Login Admin.
2. Buka **Panel Admin → Produk**.
3. Tekan **Hapus** di produk yang dipilih.
4. Konfirmasi **Ya, hapus produk**.

Jika produk belum mempunyai order/inventory, produk akan dihapus permanen beserta variannya. Jika sudah mempunyai riwayat, produk akan diarsipkan dan langsung hilang dari toko, tetapi order/invoice lama tetap aman.

Produk arsip menampilkan status **Diarsipkan** di admin dan dapat dikembalikan dengan tombol **Pulihkan**.
