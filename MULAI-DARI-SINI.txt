UPLY DIGITAL V20 — VERCEL
==========================

1. Extract ZIP.
2. Upload SEMUA isi folder V20 ke root repository GitHub.
3. Import repository ke Vercel (Framework Preset: Other).
4. Tambahkan Environment Variables:

   DATABASE_URL
   SESSION_SECRET
   CREDENTIAL_ENCRYPTION_KEY
   ADMIN_EMAIL
   ADMIN_PASSWORD
   PAYMENT_MODE=midtrans
   MIDTRANS_SERVER_KEY=Mid-server-xxxxxxxx
   MIDTRANS_IS_PRODUCTION=true
   SITE_URL=https://DOMAIN-KAMU.vercel.app
   ALLOWED_ORIGIN=https://DOMAIN-KAMU.vercel.app

5. Redeploy.
6. Cek: https://DOMAIN-KAMU.vercel.app/api/health
7. Pastikan database=connected dan payment.ready=true.
8. Di Midtrans Production set Notification URL:
   https://DOMAIN-KAMU.vercel.app/api/payment-webhook
9. Buat order BARU untuk test.
