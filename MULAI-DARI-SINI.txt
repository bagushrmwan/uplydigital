UPLY DIGITAL V21 — VERCEL

1. Extract ZIP.
2. Upload seluruh file ke repository GitHub (jangan folder pembungkus tambahan).
3. Import repository ke Vercel.
4. Tambahkan Environment Variables.
5. Deploy.
6. Buka /api/health untuk mengecek backend dan database.

UI V21 menggunakan market.css sebagai lapisan redesign di atas styles.css.
Jangan hapus market.css atau link-nya di index.html.
