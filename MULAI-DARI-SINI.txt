UPLY DIGITAL V26 — SIAP UPLOAD KE VERCEL
=========================================

1. Backup database Neon production sebagai pengaman.
2. Extract ZIP V26.
3. Replace SELURUH isi repository website lama dengan isi folder V26.
4. Commit/push ke branch main.
5. Tunggu Vercel Production Deployment selesai.
6. Environment Variables lama tetap dipakai. Tidak perlu membuat database baru.
7. Buka /api/health dan pastikan:
   - backend: connected
   - database: connected
   - hosting: vercel
   - version: 26.0
8. Hard refresh browser.
9. Tes: login > produk > + Keranjang > checkout > pesanan > Kelola Akun > logout.

Environment minimal:
DATABASE_URL
SESSION_SECRET
CREDENTIAL_ENCRYPTION_KEY
ADMIN_EMAIL
ADMIN_PASSWORD
PAYMENT_MODE
SITE_URL
ALLOWED_ORIGIN

Jika Midtrans digunakan:
MIDTRANS_SERVER_KEY
MIDTRANS_IS_PRODUCTION

V26 tidak menghapus data pelanggan/order/produk lama.
