UPLY DIGITAL V13 — UPDATE

1. Replace seluruh isi repository GitHub dengan isi folder V13.
2. Commit ke branch main dan tunggu Vercel Production deployment selesai.
3. Tambahkan Environment Variable baru di Vercel:
   CREDENTIAL_ENCRYPTION_KEY = secret acak minimal 32 karakter (Type: Secret, Production + Preview).
4. Environment lama (DATABASE_URL, SESSION_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD, Midtrans) tetap dipakai.
5. Buka /api/health lalu tes login, produk, checkout, Top Up, pembayaran, admin.

TOP UP MANUAL VIA LOGIN
- Produk kategori Top Up dipaksa menjadi fulfillment manual.
- Pelanggan mengisi email + password akun tujuan di checkout.
- Jangan pernah meminta OTP, recovery code, PIN, atau kode 2FA.
- Data login dienkripsi di database dan dihapus otomatis saat order Completed/Cancelled.
- Admin membuka data hanya dari order terkait.
- Jika penyedia layanan punya OAuth/API resmi, itu lebih disarankan daripada meminta password.
