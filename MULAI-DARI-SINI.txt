UPLY DIGITAL V27 — SIAP UPLOAD KE VERCEL
==========================================

V27 menambahkan PRODUCT VARIANT SYSTEM.
Satu produk bisa mempunyai banyak paket/harga/stok, sehingga katalog tidak penuh produk duplikat.

CARA UPDATE
1. Backup database Neon production terlebih dahulu.
2. Extract ZIP V27.
3. Replace SELURUH isi repository Uply Digital lama dengan isi V27.
4. Commit/push ke branch yang terhubung ke Vercel (biasanya main).
5. Tunggu Production Deployment selesai.
6. Environment Variables lama tetap digunakan; jangan ganti DATABASE_URL jika database sebelumnya sudah connected.
7. Buka /api/health.

TARGET HEALTH:
- backend: connected
- database: connected
- hosting: vercel
- version: 27.0
- variantSystemReady: true

CARA BUAT VARIAN
Admin -> Produk -> pilih produk -> Varian -> + Tambah Varian.

Setiap varian bisa punya:
- nama
- subtitle
- harga
- harga coret
- stok
- badge
- urutan
- aktif/nonaktif

Stok 0 = Stok Habis dan customer tidak bisa memilih.
Stok -1 = Tanpa batas (untuk produk manual).

Produk lama tanpa varian tetap bekerja normal.
Database lama tidak dihapus. V27 hanya menambah tabel/kolom dengan migration IF NOT EXISTS.
